# NoBBQ Data

> Diclaimer: This is work in progress

Here you (will) find the data from the category datasets to the evaluation of the responses. The data is separated into category-specific folders. Each folder contains the following subfolders:

1. Data prep $\rightarrow$ The jsonl file (i.e., dataset) for the category
2. Prompts and responses $\rightarrow$ The prompts and their respective responses
3. Automated scoring $\rightarrow$ The result of the automated scoring of the respective responses
